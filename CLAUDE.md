# Claude Code guidance

@AGENTS.md

This repository's agent rules live in `AGENTS.md` (shared across OpenCode, Codex,
and Claude Code). The commit-hygiene rule — no app/brand names, business-specific
naming, or external-context content in committed files, docs, or commit messages —
is documented there and enforced by the `.githooks/` pre-commit and commit-msg
scans.
